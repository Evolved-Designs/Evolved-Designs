## Choose a practical starting point

- **Planning or procuring a website, store, redesign, or digital system:** use the native [Website Procurement Readiness](https://evolveddesigns.net/website-procurement-readiness/?utm_source=github&utm_medium=profile&utm_campaign=website_procurement_readiness) path to make scope, acceptance, ownership, migration, and support decisions visible.
- **Comparing a service website with the system that accepts bookings, orders, estimates, or inquiries:** use the [Service Website Operations Parity Checklist](https://github.com/Evolved-Designs/public-website-procurement-preflight/blob/main/SERVICE-WEBSITE-OPERATIONS-PARITY-CHECKLIST.md?utm_source=github&utm_medium=profile&utm_campaign=service_operations_parity) to check identity, location, contact, hours, services, prices, policies, handoffs, and measurement.
- **Aligning brand and website decisions:** start with Evolved Designs' native [Graphic Design](https://evolveddesigns.net/graphic-design/?utm_source=github&utm_medium=profile&utm_campaign=graphic_design) service path.
- **Moving an existing site:** use the native [Website Migration Readiness Check](https://evolveddesigns.net/website-migration-check/?utm_source=github&utm_medium=profile&utm_campaign=website_migration_readiness) for dependencies, redirects, analytics, cutover, rollback, and care.
- **Taking over ongoing care:** use the native [Managed Website Support](https://evolveddesigns.net/managed-website-support/?utm_source=github&utm_medium=profile&utm_campaign=managed_website_support) path for ownership, recovery, releases, measurement, and open work.
- **Testing accessibility work:** use the native [Website Accessibility Readiness](https://evolveddesigns.net/website-accessibility-readiness/?utm_source=github&utm_medium=profile&utm_campaign=accessibility_readiness) path to turn barriers into observable acceptance evidence.
- **Exploring a research question:** choose a calm, source-aware route in Dystiny's native [Research Paths](https://dystiny.com/research-paths/?utm_source=github&utm_medium=profile&utm_campaign=dystiny_research_paths).

Each tool works in the browser without submitting the answers. If the resulting brief points to implementation work, review our [website and web-app delivery approach](https://evolveddesigns.net/web-development/?utm_source=github&utm_medium=profile&utm_campaign=developer_proof&utm_content=service_path) and bring the non-confidential version to Evolved Designs.
